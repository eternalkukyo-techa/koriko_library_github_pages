# Koriko Library (versi statis)

Versi HTML + JavaScript dari proyek_perpustakaan untuk GitHub Pages.
Data disimpan di localStorage browser, jadi tiap pengunjung punya data sendiri.

Akun awal: admin / 123

## Terbitkan di GitHub Pages
1. Buat repositori publik di GitHub, unggah semua isi folder ini ke cabang main.
2. Settings > Pages > Source: Deploy from a branch > main, folder / (root) > Save.
3. Tunggu beberapa menit, alamatnya https://USERNAME.github.io/NAMA-REPO/
